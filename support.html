자주 묻는 것

채점 결과가 실제 시험 점수인가요?

아닙니다. 공개된 평가 기준을 답안에 적용한 학습용 참고 자료이며, 등급이나 실제 점수를 예측하지 않습니다. 점수는 "평가 기준 적용 시 N/10" 형식으로만 보여 드립니다.

채점이 하루에 몇 번인가요?

하루 10회입니다. 한국·일본 시간(UTC+9) 0시에 초기화됩니다. 이미 채점한 것과 똑같은 답안을 다시 내면 저장된 결과를 돌려주며 횟수를 쓰지 않습니다.

채점이 이상합니다.

자동 판정이라 틀릴 수 있습니다. 문항 id와 쓰신 답안을 함께 보내 주시면 확인해 채점 기준을 고칩니다. 실제로 이렇게 들어온 지적으로 감점 규칙을 여러 번 고쳤습니다.

기기를 바꾸면 기록이 옮겨지나요?

지금은 옮겨지지 않습니다. 계정 없이 쓰는 구조라 학습 기록이 기기에 묶여 있고, 앱을 지우거나 기기를 바꾸면 다시 볼 수 없습니다. 서버 동기화는 추후 과제입니다.

제가 쓴 답안은 어떻게 쓰이나요?

채점 품질을 개선하는 데 씁니다(채점 기준 점검, 회귀 테스트 표본, 오류 통계, 문항 검토). 개인을 식별할 수 있는 정보와 결합하지 않으며 외부에 공개하거나 팔지 않습니다. 이용약관 제7조와 개인정보처리방침 4항에 적어 두었습니다.

제 답안을 지우고 싶습니다.

앱 설정 화면에 익명 계정 식별자(앞 8자)가 있습니다. 같은 화면의 "데이터 삭제 요청"을 누르면 식별자가 제목에 담긴 메일이 열립니다. 그대로 보내 주시면 됩니다.

한글 키보드가 없습니다.

iOS는 설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가 → 한국어, Android는 설정 → 시스템 → 언어 및 입력 → 화면 키보드에서 추가합니다. 앱 안에 자모 팔레트는 두지 않았습니다 — 실제 시험처럼 키보드로 쓰는 연습이 되도록 하기 위해서입니다.

よくあるご質問

採点結果は実際の試験の点数ですか。

いいえ。公開された評価基準を答案に適用した学習用の参考資料で、級や実際の点数を予測するものではありません。点数は「評価基準適用時 N/10」の形でのみ表示します。

採点は1日に何回できますか。

1日10回です。韓国・日本時間(UTC+9)の0時にリセットされます。すでに採点したまったく同じ答案を再提出した場合は、保存済みの結果を返し、回数を消費しません。

採点がおかしいのですが。

自動判定のため誤ることがあります。問題IDと書かれた答案を送っていただければ確認し、採点基準を直します。実際にこうしたご指摘から減点ルールを何度も修正してきました。

端末を変えると記録は移りますか。

現在は移りません。アカウントなしで使う仕組みのため学習記録は端末に紐づいており、アプリを削除したり端末を変更したりすると再び見ることはできません。サーバー同期は今後の課題です。

書いた答案はどのように使われますか。

採点品質の改善に使います(採点基準の点検、リグレッションテスト用サンプル、誤りの統計、問題の検討)。個人を特定できる情報と結合することはなく、外部に公開したり販売したりしません。利用規約 第7条とプライバシーポリシー 第4項に記載しています。

答案を削除したいのですが。

アプリの設定画面に匿名アカウント識別子(先頭8文字)が表示されます。同じ画面の「データ削除のご請求」を押すと、識別子が件名に入ったメールが開きますので、そのままお送りください。

ハングル入力のキーボードがありません。

iOSは 設定 → 一般 → キーボード → キーボード → 新しいキーボードを追加 → 韓国語、Androidは 設定 → システム → 言語と入力 → 画面キーボード から追加します。アプリ内に字母パレットは置いていません — 実際の試験と同じようにキーボードで書く練習になるようにするためです。

Common questions

Is the grading result my real exam score?

No. It is study reference material produced by applying the published assessment criteria to your answer, and it does not predict your level or actual score. Scores are only ever shown as "N/10 under the grading criteria".

How many gradings do I get per day?

Ten per day, resetting at midnight Korea/Japan time (UTC+9). Resubmitting exactly the same answer returns the stored result and does not use up a grading.

The grading looks wrong.

It is automated and it can be wrong. Send us the question id and the answer you wrote and we will look into it and fix the criteria. Reports like these have already led to several changes in the deduction rules.

Does my history move to a new device?

Not at the moment. The app works without an account, so your history is tied to the device; deleting the app or changing device means you cannot get it back. Server sync is planned work.

What happens to the answers I write?

They are used to improve grading quality — checking the criteria, building regression test samples, error statistics, and reviewing questions. They are not combined with information that could identify you, and they are never published or sold. See Terms of Service, Article 7 and Privacy Policy, section 4.

I want my answers deleted.

The app's settings screen shows the first 8 characters of your anonymous account identifier. "Request data deletion" on the same screen opens an email with that identifier in the subject line — just send it.

I have no Korean keyboard.

On iOS: Settings → General → Keyboard → Keyboards → Add New Keyboard → Korean. On Android: Settings → System → Languages & input → On-screen keyboard. We deliberately did not build a jamo palette into the app, so that you practise typing the way you will in the real exam.
